📝 To-Do List Web App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript.
This app allows users to add, edit, and remove tasks seamlessly.

🚀 Features

➕ Add Tasks – Quickly add new tasks to the list.

🖊️ Edit Tasks – Modify any existing task.

❌ Remove Tasks – Delete tasks once completed or no longer needed.

💾 Local Storage Support (optional, if you added it) – Keeps your tasks even after refreshing.

📂 Project Structure
📁 todolist-app
 ┣ 📄 index.html     # Main structure of the app
 ┣ 📄 style.css      # Styling (layout, colors, design)
 ┣ 📄 script.js      # JavaScript logic (add, edit, remove)
 ┗ 📄 README.md      # Project documentation

⚙️ How to Run

Clone or download this repository.

Open the index.html file in your browser.

Start adding, editing, and removing tasks!
